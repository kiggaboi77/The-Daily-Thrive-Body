# The Daily Thrive Body

A static wellness website: daily tips, a water tracker, a 7-day habit challenge, and articles across four pillars (Move, Nourish, Rest, Mind).

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Structure

- `index.html` — page markup
- `assets/styles.css` — styles (light/dark, responsive)
- `assets/script.js` — tips, water tracker, challenge, article filter

## Deploy

It's plain HTML/CSS/JS, so GitHub Pages works as-is: Settings → Pages → deploy from branch.
